# 🏍️ TVS Apache RTX 300 Companion App

An Android companion application concept for the **TVS Apache RTX 300**, designed to bring navigation, ride tracking, bike connectivity, and useful riding tools together in one place.

The goal is to build a clean, practical, and free-to-use companion app that enhances the riding experience while preserving a simple, motorcycle-focused interface.

## ✨ Features

- 🗺️ **In-App Navigation:** Map integration, current-location detection, destination search, and route navigation.
- 📍 **Location Services:** Phone GPS integration and map recentering.
- 🛣️ **Ride Logging:** Record rides, track distance and duration, and maintain a local ride history.
- 📊 **Ride Statistics:** View available ride metrics, including average speed and maximum speed.
- 📤 **Ride Export:** Export recorded ride data to CSV and GPX formats.
- 📡 **Bike Connectivity:** Explore Wi-Fi connectivity and supported motorcycle integration.
- 🔧 **Connection Diagnostics:** Inspect connection states and troubleshoot connectivity issues.
- 🏍️ **Live Dashboard:** Bring navigation, ride information, and supported bike data into one interface.
- 🖥️ **TFT Navigation Research:** Investigate supported methods for transferring navigation information to the motorcycle's instrument display.
- 🌑 **AMOLED Dark Theme:** A dark, motorcycle-inspired interface designed for readability.
- 🕒 **Idle Display:** A custom idle screen with clock and other available information.
- 🅿️ **Parking Location:** Save your parking position and find your way back.
- ⛽ **Fuel & Mileage Tracker:** Record refuelling, fuel expenses, and available mileage statistics.
- 💾 **Local Storage:** Keep ride history and personal tracking data on the phone without requiring a cloud account.

> **Note:** Features are at different stages of development. Availability of live bike telemetry and TFT navigation integration depends on compatible hardware and accessible communication protocols. Only verified data will be presented as real.

## 🛠️ Tech Stack

- **Platform:** Android
- **Languages:** Kotlin / Java
- **Location:** Android location services and GPS
- **Maps:** Free mapping solutions under evaluation
- **Storage:** Local persistence on the device
- **Development:** Android development tools and AI-assisted coding

The final technology choices may evolve as the project develops.

## 🎯 Project Goals

- Fix reliable current-location detection.
- Implement a fully functional destination search.
- Build persistent ride recording and ride history.
- Provide useful ride statistics and export options.
- Investigate legitimate, free navigation integration with the RTX 300 TFT.
- Improve UI consistency, accessibility, and error handling.
- Keep the application free from paid API dependencies and unexpected charges.

## 🚧 Development Status

This project is a work in progress.

Current development priorities include:

- Fixing GPS and location permissions.
- Repairing the search bar and result handling.
- Implementing the ride log and local database.
- Testing navigation and connection diagnostics.
- Auditing the interface for visual and functional bugs.
- Investigating supported TFT integration methods.

## 🔒 Privacy & Cost

Privacy and cost are important design considerations.

- Ride records are intended to remain stored locally on the device.
- No mandatory account or cloud synchronisation is planned.
- Free services are preferred.
- External service usage must respect licensing, usage limits, and privacy requirements.
- Unsupported bike telemetry will not be fabricated.
